# 🍔 FoodieApp - Android

A modern Food Delivery Android application built using **Kotlin** and **Jetpack Compose**.

This project demonstrates a clean and responsive Android UI with onboarding and authentication screens following modern Android development practices.

> **Note:** Backend services, authentication, database integration, and ordering functionality are planned for future development.

---

##  Features

- Modern Jetpack Compose UI
- Onboarding Screens
- Login UI
- Sign Up UI
- Material Design 3
- Responsive Layout
- Android Studio Project Structure

---

##  Tech Stack

- Kotlin
- Jetpack Compose
- MVVM
- Navigation Compose
- Room
- Retrofit
- Coil
- Coroutines
